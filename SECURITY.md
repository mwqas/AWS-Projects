# Security

Do not paste secrets into issues, pull requests, logs, or screenshots. If a credential is exposed, revoke it through its provider and remove the exposure; deleting a file alone does not erase Git history.

For a sensitive vulnerability, use the repository Security tab's private reporting feature if enabled. Otherwise contact the owner privately through a channel the owner publishes. This repository does not claim a configured security mailbox or response SLA.

The reference agent uses classroom assumptions: caller-supplied identity, consent bypass, an unauthenticated Gateway connection, and mock refund fixtures. Add authenticated identity, least-privilege authorization, backend policy enforcement, and idempotency before connecting real business systems. Never put real payment credentials into these fixtures.
