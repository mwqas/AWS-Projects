# AWS Projects

Hands-on AWS learning projects, worked examples, and study resources.

## Start here

### Amazon Bedrock AgentCore customer support agent

Build an educational support agent using **Strands**, **AgentCore Runtime**, **Gateway/MCP**, **Knowledge Bases**, **Memory**, **Code Interpreter**, and **Browser**.

- [Project guide and quick start](agentcore-customer-support/README.md)
- [Download the 38-page guided book](agentcore-customer-support/AgentCore-Guided-Learning-Book.pdf)
- [Read the book on GitHub](agentcore-customer-support/companion/book.md)
- [Complete reference agent](agentcore-customer-support/companion/reference/main.py)
- [Six-week learning plan](agentcore-customer-support/docs/LEARNING_PATH.md)
- [Official learning resources](agentcore-customer-support/docs/RESOURCES.md)
- [Test and submission guide](agentcore-customer-support/docs/TESTING.md)

Start with the offline exercises: no AWS account or credentials required. Cloud labs use your own AWS resources and can incur charges.

## Repository scope

This is an educational implementation, not a production payment system. Cloud configuration, credentials, customer data, and historical account-specific screenshots are excluded. CI runs offline checks; it does not deploy to AWS.
